Handwritten Digit Recognition Using MNIST

This project uses a simple neural network trained on the MNIST dataset to recognize handwritten digits from 0 to 9. Draw a digit below and the model will predict it.

Instructions

  1. Draw one digit (0-9) in the black box using your mouse or finger.
  2. Draw it big, thick, and in the middle for the best result.
  3. Click Predict Digit to see the answer.
  4. Click Clear to draw again.
